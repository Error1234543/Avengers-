NEET Chemistry Practice - Structure of Atom (Part 1)

This practice set contains 12 multiple-choice questions (MCQs) focused on the topic 'Structure of Atom' for NEET. Each question has four options, and only one is correct. Select the correct answer for each question. This is part 1 of a 25-question practice series.

1. Which of the following experiments provided evidence for the existence of a small, dense, positively charged nucleus in an atom?

A. Cathode ray experiment
B. Millikan's oil drop experiment
C. Rutherford's gold foil experiment
D. Thomson's plum pudding model
Answer: C

Rutherford's gold foil experiment demonstrated that atoms have a small, dense, positively charged nucleus by observing the scattering of alpha particles. Most particles passed through the foil, but some were deflected at large angles, indicating a concentrated positive charge.

2. The electronic configuration of an element with atomic number 24 is:

A. 1s² 2s² 2p⁶ 3s² 3p⁶ 3d⁴ 4s²
B. 1s² 2s² 2p⁶ 3s² 3p⁶ 3d⁵ 4s¹
C. 1s² 2s² 2p⁶ 3s² 3p⁶ 4s² 3d⁴
D. 1s² 2s² 2p⁶ 3s² 3p⁶ 4s¹ 3d⁵
Answer: B

For elements with atomic numbers 24 (Chromium) and 29 (Copper), the electronic configuration is an exception to the Aufbau principle due to the stability of half-filled and fully-filled d-orbitals. Chromium's configuration is 1s² 2s² 2p⁶ 3s² 3p⁶ 3d⁵ 4s¹.

3. What is the maximum number of electrons that can occupy the n=3 energy level?

A. 8
B. 18
C. 32
D. 2
Answer: B

The maximum number of electrons in an energy level is given by the formula 2n², where n is the principal quantum number. For n=3, the maximum number of electrons is 2 × 3² = 18.

4. The wavelength of a photon emitted during a transition from n=4 to n=2 in a hydrogen atom is closest to:

A. 486 nm
B. 656 nm
C. 434 nm
D. 410 nm
Answer: A

The transition from n=4 to n=2 in a hydrogen atom corresponds to the Balmer series. Using the Rydberg formula, the wavelength for this transition is calculated as approximately 486 nm (blue-green line in the hydrogen spectrum).

5. An electron in a hydrogen atom transitions from n=3 to n=1. The energy of the emitted photon is:

A. 12.09 eV
B. 10.2 eV
C. 1.89 eV
D. 0.66 eV
Answer: A

The energy of the photon emitted during a transition from n=3 to n=1 in a hydrogen atom can be calculated using the formula E = -13.6 (1/n₁² - 1/n₂²) eV. For n₁=1 and n₂=3, E = -13.6 (1/1² - 1/3²) = -13.6 (1 - 1/9) = -13.6 × 8/9 = -12.09 eV. The negative sign indicates energy is released, so the magnitude is 12.09 eV.

6. Which of the following sets of quantum numbers is not possible for an electron in an atom?

A. n=2, l=1, mₗ=0, mₛ=+1/2
B. n=3, l=2, mₗ=-2, mₛ=-1/2
C. n=1, l=0, mₗ=0, mₛ=+1/2
D. n=2, l=2, mₗ=1, mₛ=-1/2
Answer: D

For n=2, the possible values of l are 0 and 1 (since l can range from 0 to n-1). The set n=2, l=2 is invalid because l cannot be equal to n.

7. The angular momentum of an electron in the n=2 orbit of a hydrogen atom is:

A. h/π
B. h/2π
C. √2 h/2π
D. 2h/π
Answer: C

According to Bohr's model, the angular momentum (L) of an electron in the nth orbit is given by L = n(h/2π). For n=2, L = 2(h/2π) = h/π. However, in quantum mechanics, the angular momentum is quantized as L = √[l(l+1)] (h/2π). For n=2, l can be 0 or 1. For l=1, L = √[1(1+1)] (h/2π) = √2 h/2π.

8. Which of the following transitions in a hydrogen atom emits radiation of the shortest wavelength?

A. n = 3 to n = 2
B. n = 4 to n = 3
C. n = 2 to n = 1
D. n = 5 to n = 4
Answer: C

The wavelength of emitted radiation is inversely proportional to the energy difference between the levels. The transition from n = 2 to n = 1 involves the largest energy difference, thus emitting radiation of the shortest wavelength.

9. The number of radial nodes in the 3p orbital of a hydrogen atom is:

A. 0
B. 1
C. 2
D. 3
Answer: B

For an orbital with principal quantum number n and azimuthal quantum number l, the number of radial nodes is given by n - l - 1. For the 3p orbital, n = 3 and l = 1, so the number of radial nodes is 3 - 1 - 1 = 1.

10. The magnetic quantum number for an electron in a 3d orbital can have the following values:

A. 0, ±1, ±2
B. ±1, ±2, ±3
C. 0, ±1
D. ±2 only
Answer: A

For a d orbital, the azimuthal quantum number l = 2. The magnetic quantum number (mₗ) can take values from -l to +l, including zero. Thus, mₗ = 0, ±1, ±2.

11. The number of angular nodes in a 4f orbital is:

A. 0
B. 1
C. 2
D. 3
Answer: D

The number of angular nodes in an orbital is equal to the azimuthal quantum number l. For an f orbital, l = 3, so there are 3 angular nodes.

12. An electron in a hydrogen atom transitions from n = 4 to n = 2. The wavelength of the emitted photon is in which region of the electromagnetic spectrum?

A. Infrared
B. Visible
C. Ultraviolet
D. X-ray
Answer: B

The transition from n = 4 to n = 2 in a hydrogen atom corresponds to the Balmer series, which emits visible light. Specifically, this transition produces a photon in the visible region (blue-green light).

13. An electron in a hydrogen atom transitions from the n = 4 energy level to the n = 2 energy level. The wavelength of the emitted photon is closest to which of the following? (Rydberg constant, R = 1.097 × 10^7 m^-1)

A. 486 nm
B. 656 nm
C. 434 nm
D. 410 nm
Answer: A

Using the Rydberg formula for hydrogen: 1/λ = R (1/n₁² - 1/n₂²), where n₁ = 2 and n₂ = 4. Substituting values: 1/λ = 1.097 × 10^7 (1/4 - 1/16) = 1.097 × 10^7 × 3/16 = 2.056875 × 10^6 m^-1. Thus, λ = 1 / (2.056875 × 10^6) ≈ 4.86 × 10^-7 m = 486 nm. This corresponds to the Balmer series transition for hydrogen.
