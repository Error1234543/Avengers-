This set contains 12 exam-focused multiple-choice questions (MCQs) on the topic 'Structure of Atom' for NEET preparation. Each question carries +4 marks for a correct answer and -1 mark for an incorrect answer. Select the most appropriate answer from the given options (A, B, C, D).

1. Which of the following statements about the Rutherford model of the atom is INCORRECT?

A. The atom consists of a positively charged nucleus at the center.
B. Electrons revolve around the nucleus in fixed circular orbits.
C. Most of the space in an atom is empty.
D. The model explains the stability of the atom without radiation loss.
Answer: D

The Rutherford model fails to explain the stability of the atom because, according to classical electromagnetic theory, an accelerating electron (revolving around the nucleus) should continuously emit radiation, lose energy, and eventually spiral into the nucleus. This instability is not addressed in the model.

2. The ratio of the radii of the first three Bohr orbits of the hydrogen atom is:

A. 1 : 2 : 3
B. 1 : 4 : 9
C. 1 : 8 : 27
D. 1 : √2 : √3
Answer: B

According to Bohr’s model, the radius of the nth orbit of a hydrogen atom is given by rₙ = n²a₀, where a₀ is the Bohr radius. Thus, the ratio of the radii of the first three orbits (n = 1, 2, 3) is 1² : 2² : 3² = 1 : 4 : 9.

3. The de Broglie wavelength of an electron moving with a velocity of 1.5 × 10⁶ m/s is approximately: (Given: mass of electron = 9.11 × 10⁻³¹ kg, h = 6.63 × 10⁻³⁴ J s)

A. 4.85 × 10⁻¹⁰ m
B. 4.85 × 10⁻¹¹ m
C. 4.85 × 10⁻⁹ m
D. 4.85 × 10⁻⁸ m
Answer: A

The de Broglie wavelength (λ) is given by λ = h / (m × v). Substituting the given values: λ = (6.63 × 10⁻³⁴) / (9.11 × 10⁻³¹ × 1.5 × 10⁶) ≈ 4.85 × 10⁻¹⁰ m.

4. Which of the following quantum numbers determines the orientation of an orbital in space?

A. Principal quantum number (n)
B. Azimuthal quantum number (l)
C. Magnetic quantum number (mₗ)
D. Spin quantum number (mₛ)
Answer: C

The magnetic quantum number (mₗ) determines the orientation of an orbital in space. It can take integer values ranging from -l to +l, where l is the azimuthal quantum number.

5. The correct set of quantum numbers for the valence electron of a sodium atom (Z = 11) in its ground state is:

A. n = 3, l = 0, mₗ = 0, mₛ = +1/2
B. n = 2, l = 1, mₗ = 0, mₛ = -1/2
C. n = 3, l = 1, mₗ = 1, mₛ = +1/2
D. n = 3, l = 2, mₗ = 0, mₛ = -1/2
Answer: A

The electronic configuration of sodium (Z = 11) is 1s² 2s² 2p⁶ 3s¹. The valence electron is in the 3s orbital, so its quantum numbers are n = 3, l = 0 (s orbital), mₗ = 0 (only possible value for l = 0), and mₛ = +1/2 or -1/2. Option A correctly represents one possible set.

6. Which of the following statements about the Heisenberg Uncertainty Principle is CORRECT?

A. It is possible to simultaneously determine the exact position and momentum of an electron with high precision.
B. The principle applies only to macroscopic objects and not to subatomic particles.
C. The product of the uncertainties in position (Δx) and momentum (Δp) of a particle is always greater than or equal to h/4π.
D. The principle is a consequence of the wave nature of light and does not apply to matter waves.
Answer: C

The Heisenberg Uncertainty Principle states that it is impossible to simultaneously determine the exact position and momentum of a particle with absolute precision. Mathematically, Δx × Δp ≥ h/4π, where h is Planck’s constant.

7. The energy of an electron in the nth orbit of a hydrogen atom is given by Eₙ = -13.6/n² eV. What is the energy required to excite an electron from the ground state to the n = 3 energy level?

A. 12.09 eV
B. 10.2 eV
C. 13.6 eV
D. 1.51 eV
Answer: A

The energy of the ground state (n = 1) is E₁ = -13.6 eV. The energy of the n = 3 level is E₃ = -13.6 / 3² = -1.51 eV. The energy required to excite the electron from n = 1 to n = 3 is ΔE = E₃ - E₁ = -1.51 - (-13.6) = 12.09 eV.

8. The number of radial nodes in a 3p orbital is:

A. 0
B. 1
C. 2
D. 3
Answer: B

The number of radial nodes in an orbital is given by n - l - 1, where n is the principal quantum number and l is the azimuthal quantum number. For a 3p orbital, n = 3 and l = 1, so the number of radial nodes = 3 - 1 - 1 = 1.

9. The correct order of increasing energy of the orbitals in a multi-electron atom is:

A. 3s < 3p < 4s < 3d
B. 3s < 3p < 3d < 4s
C. 3s < 4s < 3p < 3d
D. 3s < 3p < 3d < 4p
Answer: A

In a multi-electron atom, the energy of orbitals increases with the principal quantum number (n) and the azimuthal quantum number (l). The correct order of increasing energy is 3s < 3p < 4s < 3d, as the 4s orbital has lower energy than the 3d orbital due to shielding effects.

10. Which quantum number determines the shape of an atomic orbital?

A. Principal quantum number (n)
B. Azimuthal quantum number (l)
C. Magnetic quantum number (m_l)
D. Spin quantum number (m_s)
Answer: B

The azimuthal quantum number (l) determines the shape of an atomic orbital. For example, l = 0 corresponds to an s-orbital (spherical), l = 1 to a p-orbital (dumbbell-shaped), etc.

11. The correct set of quantum numbers for the last electron in a chlorine atom (Z = 17) is:

A. n = 3, l = 1, m_l = 0, m_s = +1/2
B. n = 3, l = 0, m_l = 0, m_s = -1/2
C. n = 2, l = 1, m_l = -1, m_s = +1/2
D. n = 3, l = 1, m_l = -1, m_s = -1/2
Answer: D

The electronic configuration of chlorine (Z = 17) is 1s² 2s² 2p⁶ 3s² 3p⁵. The last electron enters the 3p orbital. For the 3p⁵ electron, the quantum numbers are n = 3, l = 1, m_l = -1 (or 0 or +1), and m_s = -1/2 (since the 3p subshell is half-filled).

12. Which of the following transitions in the hydrogen atom will emit the highest energy photon?

A. None
B. n = 3 to n = 2
C. n = 4 to n = 3
D. n = 5 to n = 4
Answer: A

The energy of the photon emitted is given by ΔE = E_final - E_initial = -13.6 (1/n_final² - 1/n_initial²) eV. The transition from n = 2 to n = 1 has the largest ΔE (highest energy photon) because the energy difference between lower levels is greater than between higher levels.

13. The correct order of increasing energy of atomic orbitals is:

A. 3s < 3p < 4s < 3d
B. 3s < 3p < 3d < 4s
C. 3s < 4s < 3p < 3d
D. 3s < 3p < 4s = 3d
Answer: A

The correct order of increasing energy of atomic orbitals is given by the (n + l) rule. For 3s (n + l = 3), 3p (n + l = 4), 4s (n + l = 4), and 3d (n + l = 5), the order is 3s < 3p < 4s < 3d. Note that 4s and 3p have the same (n + l) value, but 3p has lower energy due to lower n.

14. The maximum number of electrons that can occupy the f-subshell is:

A. 2
B. 6
C. 10
D. 14
Answer: D

The f-subshell corresponds to l = 3, which has (2l + 1) = 7 orbitals. Each orbital can hold 2 electrons, so the maximum number of electrons in the f-subshell is 7 × 2 = 14.

15. The electronic configuration of Cr (Z = 24) is an exception to the Aufbau principle. Which of the following correctly represents it?

A. [Ar] 3d⁴ 4s²
B. [Ar] 3d⁵ 4s¹
C. [Ar] 3d⁶ 4s⁰
D. [Ar] 3d³ 4s² 4p¹
Answer: B

Chromium (Z = 24) has an exceptional electronic configuration due to the stability of half-filled subshells. Its configuration is [Ar] 3d⁵ 4s¹, not [Ar] 3d⁴ 4s², to achieve greater stability.

16. Which of the following orbitals has a spherical shape?

A. p-orbital
B. d-orbital
C. f-orbital
D. s-orbital
Answer: D

The s-orbital has a spherical shape because it corresponds to l = 0, which has no angular dependence. The p, d, and f orbitals have directional shapes (e.g., dumbbell, cloverleaf).

17. An electron in a hydrogen atom transitions from the n = 4 energy level to the n = 2 energy level. If the Rydberg constant (R) is 1.097 × 10^7 m^-1, the wavelength of the emitted photon is closest to:

A. 486 nm
B. 656 nm
C. 972 nm
D. 121 nm
Answer: A

Using the Rydberg formula for hydrogen: 1/λ = R (1/n₁² - 1/n₂²), where n₁ = 2 and n₂ = 4. Substituting values: 1/λ = 1.097 × 10^7 (1/4 - 1/16) = 1.097 × 10^7 × (3/16) = 2.056875 × 10^6 m^-1. Thus, λ = 1 / (2.056875 × 10^6) ≈ 4.86 × 10^-7 m = 486 nm. This corresponds to the Balmer series transition, which emits visible light.

18. Which of the following statements regarding the quantum numbers of an electron in an atom is INCORRECT?

A. The principal quantum number (n) determines the energy of the electron in a hydrogen-like atom.
B. The magnetic quantum number (mₗ) can have values ranging from -l to +l, including zero.
C. The spin quantum number (mₛ) can take only two values: +1/2 and -1/2, representing the two possible spin orientations.
D. The azimuthal quantum number (l) determines the shape of the orbital and can have values from 0 to n, inclusive.
Answer: D

The azimuthal quantum number (l) determines the shape of the orbital and can have values ranging from 0 to (n - 1), not 0 to n. For example, if n = 2, l can be 0 or 1, but not 2. The other statements are correct: (A) n determines energy in hydrogen-like atoms, (B) mₗ ranges from -l to +l, and (C) mₛ can only be +1/2 or -1/2.
