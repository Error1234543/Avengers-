PYQ-STYLE PRACTICE — NEET PYQ-STYLE PRACTICE: Redox Reactions (Part 1 of 2)

NEETEnglishPYQ-Style Practice

This set contains 12 exam-focused multiple-choice questions on Redox Reactions, designed to match the style and difficulty of NEET Chemistry. Each question carries +4 marks for a correct answer and -1 mark for an incorrect answer. Select the most appropriate option for each question.

1. In the reaction: 2FeCl3 + SnCl2 → 2FeCl2 + SnCl4, which species is oxidized?

A. Fe³⁺
B. Sn²⁺
C. Cl⁻
D. Fe²⁺
Answer: B

Oxidation involves loss of electrons. Sn²⁺ loses 2 electrons to form Sn⁴⁺, increasing its oxidation state from +2 to +4. Fe³⁺ is reduced to Fe²⁺, gaining an electron.

2. What is the oxidation number of chromium in K₂Cr₂O₇?

A. +3
B. +6
C. +7
D. +12
Answer: B

Let the oxidation number of Cr be x. The equation is: 2(+1) + 2x + 7(-2) = 0 → 2 + 2x - 14 = 0 → 2x = +12 → x = +6.

3. Which of the following is a disproportionation reaction?

A. 2H₂O₂ → 2H₂O + O₂
B. Zn + 2HCl → ZnCl₂ + H₂
C. 2KClO₃ → 2KCl + 3O₂
D. Cl₂ + 2NaOH → NaCl + NaClO + H₂O
Answer: D

In disproportionation, the same species is both oxidized and reduced. Here, chlorine (0) is oxidized to +1 (NaClO) and reduced to -1 (NaCl).

4. In the redox reaction: MnO₄⁻ + 8H⁺ + 5e⁻ → Mn²⁺ + 4H₂O, the equivalent weight of KMnO₄ (M = 158 g/mol) is:

A. 31.6 g/eq
B. 79 g/eq
C. 158 g/eq
D. 39.5 g/eq
Answer: A

Equivalent weight = Molar mass / n-factor. Here, n-factor = 5 (electrons transferred). Thus, 158 / 5 = 31.6 g/eq.

5. Which statement about the reaction: 2Cu⁺ → Cu²⁺ + Cu is correct?

A. Cu⁺ is reduced to Cu
B. Cu⁺ is oxidized to Cu²⁺
C. Cu⁺ acts as both oxidizing and reducing agent
D. The reaction is not a redox reaction
Answer: C

This is a disproportionation reaction where Cu⁺ (oxidation state +1) is both oxidized to Cu²⁺ (+2) and reduced to Cu (0). Thus, Cu⁺ acts as both oxidizing and reducing agent.

6. The oxidation state of nitrogen in NH₄NO₃ is:

A. -3 in NH₄⁺ and +5 in NO₃⁻
B. -3 in both ions
C. +5 in both ions
D. 0 in NH₄⁺ and +5 in NO₃⁻
Answer: A

In NH₄⁺, N has oxidation state -3 (x + 4(+1) = +1 → x = -3). In NO₃⁻, N has oxidation state +5 (x + 3(-2) = -1 → x = +5).

7. In the reaction: 2Na + Cl₂ → 2NaCl, the reducing agent is:

A. Na
B. Cl₂
C. NaCl
D. Both Na and Cl₂
Answer: A

The reducing agent is the species that gets oxidized (loses electrons). Here, Na (0) is oxidized to Na⁺ (+1), so Na is the reducing agent.

8. What is the n-factor of K₂Cr₂O₇ in acidic medium when it is reduced to Cr³⁺?

A. 2
B. 3
C. 6
D. 12
Answer: C

In K₂Cr₂O₇, Cr has oxidation state +6. It is reduced to Cr³⁺ (+3). For 2 Cr atoms, total change = 2 × (6 - 3) = 6. Thus, n-factor = 6.

9. Which of the following reactions is NOT a redox reaction?

A. 2H₂ + O₂ → 2H₂O
B. AgNO₃ + NaCl → AgCl + NaNO₃
C. Zn + CuSO₄ → ZnSO₄ + Cu
D. 2KI + Cl₂ → 2KCl + I₂
Answer: B

In AgNO₃ + NaCl → AgCl + NaNO₃, no change in oxidation states occurs (Ag⁺, NO₃⁻, Na⁺, Cl⁻ remain unchanged). Thus, it is not a redox reaction.

10. In the reaction: 3ClO⁻ → 2Cl⁻ + ClO₃⁻, the equivalent weight of ClO⁻ (M = 51.5 g/mol) is:

A. 17.17 g/eq
B. 25.75 g/eq
C. 51.5 g/eq
D. 34.33 g/eq
Answer: B

This is a disproportionation reaction. For ClO⁻ to Cl⁻, n-factor = 2 (oxidation state changes from +1 to -1). For ClO⁻ to ClO₃⁻, n-factor = 4 (oxidation state changes from +1 to +5). Total n-factor = 2 + 4 = 6 for 3 ClO⁻ ions. Thus, equivalent weight = (3 × 51.5) / 6 = 25.75 g/eq.

11. The oxidation number of sulfur in S₂O₈²⁻ is:

A. +2
B. +6
C. +7
D. +8
Answer: B

Let the oxidation number of S be x. The equation is: 2x + 8(-2) = -2 → 2x - 16 = -2 → 2x = +14 → x = +6.

12. In the reaction: 2FeCl₃ + SnCl₂ → 2FeCl₂ + SnCl₄, which of the following statements is correct?

A. FeCl₃ is reduced and acts as the oxidizing agent.
B. SnCl₂ is oxidized and acts as the reducing agent.
C. FeCl₃ is oxidized and acts as the reducing agent.
D. SnCl₄ is reduced and acts as the oxidizing agent.
Answer: B

In the given reaction, Fe³⁺ in FeCl₃ is reduced to Fe²⁺ (gains electrons), while Sn²⁺ in SnCl₂ is oxidized to Sn⁴⁺ (loses electrons). Thus, SnCl₂ acts as the reducing agent, and FeCl₃ acts as the oxidizing agent.

13. Which of the following species can act as both an oxidizing and a reducing agent?

A. MnO₄⁻
B. H₂O₂
C. Fe³⁺
D. Cr₂O₇²⁻
Answer: B

H₂O₂ (hydrogen peroxide) can act as both an oxidizing and a reducing agent because it contains oxygen in the -1 oxidation state, which can either be oxidized to O₂ (0) or reduced to H₂O (-2).

14. In the reaction: 2Al + 3Cu²⁺ → 2Al³⁺ + 3Cu, the number of electrons transferred per aluminum atom is:

A. 1
B. 2
C. 3
D. 6
Answer: C

In the given reaction, aluminum (Al) is oxidized from 0 to +3 oxidation state, losing 3 electrons per atom. Thus, 3 electrons are transferred per aluminum atom.

15. In the reaction: Cl₂ + 2OH⁻ → Cl⁻ + ClO⁻ + H₂O, chlorine undergoes:

A. Oxidation only
B. Reduction only
C. Disproportionation
D. Neither oxidation nor reduction
Answer: C

In this reaction, chlorine (Cl₂) is simultaneously oxidized to ClO⁻ (+1 oxidation state) and reduced to Cl⁻ (-1 oxidation state). This is a disproportionation reaction.

16. The equivalent weight of H₂SO₄ in the reaction: NaOH + H₂SO₄ → NaHSO₄ + H₂O is:

A. 49
B. 98
C. 196
D. 24.5
Answer: B

In this reaction, H₂SO₄ acts as a monoprotic acid (only one H⁺ is replaced). The equivalent weight is equal to its molar mass (98 g/mol) divided by 1, which is 98 g/equiv.

17. Which of the following statements about the reaction: 2KMnO₄ + 16HCl → 2KCl + 2MnCl₂ + 5Cl₂ + 8H₂O is correct?

A. HCl is oxidized to Cl₂.
B. KMnO₄ is reduced to MnCl₂.
C. The oxidation number of Mn changes from +7 to +2.
D. All of the above.
Answer: D

In this reaction, HCl is oxidized to Cl₂ (oxidation number of Cl changes from -1 to 0), KMnO₄ is reduced to MnCl₂ (oxidation number of Mn changes from +7 to +2), and all the statements are correct.

18. In the reaction: 2FeCl₃ + H₂S → 2FeCl₂ + 2HCl + S, which of the following statements correctly identifies the oxidizing and reducing agents?

A. FeCl₃ is the oxidizing agent, and H₂S is the reducing agent.
B. FeCl₃ is the reducing agent, and H₂S is the oxidizing agent.
C. Both FeCl₃ and H₂S act as oxidizing agents.
D. Neither FeCl₃ nor H₂S acts as an oxidizing or reducing agent.
Answer: A

In the given reaction, FeCl₃ is reduced to FeCl₂ (Fe³⁺ gains an electron to become Fe²⁺), making it the oxidizing agent. H₂S is oxidized to sulfur (S²⁻ loses electrons to form S), making it the reducing agent. The correct identification is FeCl₃ as the oxidizing agent and H₂S as the reducing agent.

19. In the reaction: 2FeCl₃ + H₂S → 2FeCl₂ + 2HCl + S, which element undergoes oxidation?

A. Iron (Fe)
B. Chlorine (Cl)
C. Sulfur (S)
D. Hydrogen (H)
Answer: C

In the given reaction, sulfur in H₂S changes its oxidation state from -2 to 0 (in elemental sulfur, S). This increase in oxidation state indicates oxidation. Iron (Fe) changes from +3 to +2, indicating reduction, while chlorine and hydrogen remain in the same oxidation states.

20. Which of the following statements is correct regarding the redox reaction: MnO₄⁻ + 5Fe²⁺ + 8H⁺ → Mn²⁺ + 5Fe³⁺ + 4H₂O?

A. MnO₄⁻ is the reducing agent and Fe²⁺ is the oxidizing agent.
B. MnO₄⁻ is the oxidizing agent and Fe²⁺ is the reducing agent.
C. Both MnO₄⁻ and Fe²⁺ act as oxidizing agents.
D. The reaction is not a redox reaction as no change in oxidation states occurs.
Answer: B

In this reaction, Mn in MnO₄⁻ is reduced from +7 to +2 (oxidizing agent), while Fe²⁺ is oxidized to Fe³⁺ (reducing agent). The change in oxidation states confirms it is a redox reaction, and the roles of the species as oxidizing or reducing agents are correctly identified in option B.
